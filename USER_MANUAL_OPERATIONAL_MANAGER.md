## Getting Started

### Logging In

1. Navigate to the salon management system login page
2. Enter your **email address**
3. Enter your **password**
4. Click **"Sign In"**

### Role Selection

If you have multiple roles:
1. Select **"Operational Manager"** from the role selection screen
2. The operational manager dashboard will load
3. You'll have visibility across all branches

### Initial Setup

- Review your organization's branches
- Set your notification preferences
- Familiarize yourself with dashboard metrics
- Review key financial/performance data

## Branch Management

### Viewing All Branches

1. Click **"Branches"** from the menu
2. View all branches in the organization
3. Each branch shows:
   - Branch name and location
   - Manager name
   - Status (Active/Inactive)
   - Staff count
   - Key metrics

### Branch Details

Click on any branch to view:

- **Branch Information**
  - Name, address, phone
  - Branch manager
  - Operating hours
  - Contact details

- **Performance Metrics**
  - Revenue this month
  - Total staff
  - Active appointments today
  - Key performance indicators

- **Recent Activity**
  - Latest transactions
  - Staff changes
  - System events
  - Alerts

- **Staff Roster**
  - All staff at branch
  - Positions and status
  - Contact information

### Branch Settings Access

As operational manager, you can:

1. Click on a branch
2. Go to **"Settings"** or **"Configuration"**
3. View (and potentially edit):
   - Operating hours
   - Holiday calendar
   - Service pricing
   - Payment methods
   - Staff assignments

*Note: Some settings may be branch-manager-controlled*

### Creating New Branches

*If you have this permission:*

1. Click **"Branches"**
2. Click **"New Branch"** or **"Add Branch"**
3. Enter branch information:
   - Branch name
   - Location/address
   - Phone number
   - Operating hours
   - Branch manager (assign)
4. Configure initial settings
5. Click **"Save"**

### Monitoring Branch Health

Use the dashboard to identify branches needing attention:

- **Low Revenue** - Underperforming locations
- **High Staff Turnover** - Staffing issues
- **High Complaints** - Quality issues
- **Low Inventory** - Stock problems
- **Pending Leave** - Scheduling concerns

## Calendar & Approval Management

### Organization-Wide Calendar

1. Click **"Calendar"** from the menu
2. View all branch calendars combined
3. Color-coded by branch for easy identification
4. See:
   - Branch closures
   - Staff leave
   - Special events
   - Holidays

### Branch Calendar Approval

Branch managers submit calendars for approval:

1. Click **"Calendar Approval"** from the menu
2. View **"Pending Approvals"**
3. Each pending calendar shows:
   - Branch name
   - Submitted date
   - Changes from previous calendar
   - Effective date

### Reviewing Branch Calendars

1. Click on a pending calendar
2. Review proposed changes:
   - Operating hours
   - Branch closures
   - Holidays
   - Special hours
3. Check for conflicts with:
   - Organization-wide holidays
   - Other branches
   - Corporate policy

### Approving Calendars

If acceptable:

1. Click **"Approve"**
2. Optional: Add comments
3. Click **"Confirm"**
4. Branch manager notified
5. Calendar becomes active

### Requesting Changes

If calendar needs revision:

1. Click **"Request Changes"** or **"Reject"**
2. Enter required changes:
   - Specific issues
   - What needs adjustment
   - Deadline for resubmission
3. Click **"Send"**
4. Branch manager receives feedback
5. They resubmit after making changes

### Establishing Organization Holidays

Set company-wide holidays:

1. Go to **"Calendar"** or **"Calendar Approval"**
2. Click **"Add Organization Holiday"** (if available)
3. Enter:
   - Holiday name
   - Date
   - Whether all branches are closed
4. Save
5. Appears on all branch calendars

## Leave Management

### Reviewing Staff Leave Across Branches

1. Click **"Leave Management"** from the menu
2. View all pending leave requests:
   - Staff name and branch
   - Leave type
   - Requested dates
   - Current status

### Leave Request Details

Each request shows:

- **Staff Member** - Who's requesting
- **Branch** - Their branch
- **Leave Type** - Vacation, sick, personal, etc.
- **Duration** - Number of days
- **Dates** - Specific dates requested
- **Reason** - Why they need leave (if provided)
- **Submitted** - When request was made

### Approving Leave Requests

1. Review the leave request
2. Check for:
   - Staffing impact
   - Customer commitments
   - Department needs
3. If acceptable:
   - Click **"Approve"**
   - Optional: Add comments
   - Click **"Confirm"**
4. Staff member notified

### Denying Leave Requests

1. If request conflicts with business needs:
   - Click **"Deny"**
   - Enter reason for denial
   - Suggest alternative dates if appropriate
   - Click **"Send"**
2. Staff member receives denial notification
3. They can resubmit with different dates

### Leave Across Branches

Monitor leave across organization:

1. Go to **"Leave Management"**
2. View all approved leave
3. Identify if multiple key staff are out simultaneously
4. Assess organization-wide impact

### Tracking Leave Balance

If your salon tracks leave allocation:

1. Go to **"Leave Management"**
2. View staff leave balance:
   - Days allocated
   - Days used
   - Days remaining
3. Plan around limited availability

## FAQ & Troubleshooting

### Branch Management

**Q: How do I view performance for a specific branch?**
A: Click "Branches", select the branch, then "Branch Performance" or click "Branch Performance" and filter by that branch.

**Q: What if a branch manager submits an unacceptable calendar?**
A: Go to "Calendar Approval", click "Request Changes", explain what needs adjustment, and they'll resubmit.

**Q: Can I directly edit a branch's settings?**
A: Some settings you can edit; others are branch-manager controlled. Try to edit—system will show what you can/can't change.

### Financial Questions

**Q: How do I find a deposit discrepancy?**
A: Go to "Deposits", find the deposit, click "Review" to see transactions for that period, compare to bank statement.

**Q: What should I do if a branch has significantly lower revenue?**
A: Review their performance metrics, analyze what's different, schedule meeting with branch manager to discuss.

**Q: How do I track commission across all branches?**
A: This is tracked at branch level. Review individual branch reports or go to Reports → Commission Report.

### Leave Management

**Q: Can I see why a staff member requested leave?**
A: Yes, open the leave request—reason is shown (if they provided one).

**Q: What if two key staff at same branch need leave same period?**
A: Assess impact, may need to deny one and suggest alternative dates.

### Inventory Questions

**Q: How do I know if branches need restocking?**
A: Check Inventory dashboard for low-stock alerts, or go to Inventory to see status across branches.

**Q: Can I move stock between branches?**
A: Not directly through your dashboard. Contact the inventory controller or branch manager to coordinate transfer.

**Q: Why is one branch's inventory much higher than others?**
A: May reflect branch size, service mix, or recent orders. Review with branch manager.

### Reporting

**Q: How do I compare performance between two branches?**
A: Go to "Branch Performance", select specific branches in filter, use comparison view.

**Q: Can I see year-over-year growth?**
A: Yes, in reports, select date range for this year and comparison period for last year.

**Q: How do I export a report to share with leadership?**
A: Open report, click "Export", select PDF or Excel, email or share the file.

### Technical Issues

**Q: Why can't I see data from a specific branch?**
A: Check your permissions. If you should have access, contact IT.

**Q: A report isn't loading.**
A: Try refreshing the page. If persists, contact IT or try different browser.

**Q: Why are numbers different between two reports?**
A: Check date ranges and filters—they may be set differently. Verify time zone alignment.
