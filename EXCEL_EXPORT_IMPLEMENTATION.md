# Excel Export Implementation Plan

## Overview
Replace existing Excel export button functions with fully formatted Excel exports that match the printed report format, including colors, highlights, borders, and proper styling.

## Library to Use
**ExcelJS** - Provides comprehensive Excel formatting capabilities:
- Cell styling (fonts, colors, borders, alignment)
- Number formatting (currency, dates)
- Column widths and row heights
- Merged cells
- Multiple sheets
- Rich formatting options

## Installation
```bash
npm install exceljs
```

## Excel Format Structure

### Standard Report Format
Each Excel export will include:

1. **Header Section** (Rows 1-2)
   - Row 1: "DAVID'S SALON" - Bold, 20pt, centered, merged cells
   - Row 2: Report Title - Bold, 16pt, centered, merged cells
   - Background: Light blue (#E3F2FD)

2. **Filters Section** (Row 4)
   - "FILTERS APPLIED: [filter text]"
   - Bold, 10pt, centered, merged cells
   - Background: Light gray (#F5F5F5)
   - Border: All sides

3. **Summary Stats Section** (Row 6)
   - Grid layout showing key metrics
   - Bold labels, large numbers
   - Background: Light yellow (#FFF9C4)
   - Borders around each stat box

4. **Data Table** (Starting Row 8)
   - **Header Row**: 
     - Bold, white text
     - Dark blue background (#1E3A8A)
     - All borders
     - Center/Right aligned as appropriate
   - **Data Rows**:
     - Alternating row colors (white and light gray #F9FAFB)
     - Borders on all cells
     - Number formatting for currency (₱#,##0.00)
     - Right-align for numbers, left for text, center for counts
   - **Grand Total Row**:
     - Bold text
     - Gray background (#E0E0E0)
     - Top border (2px solid)
     - "GRAND TOTAL:" label left-aligned

5. **Footer Section** (After data)
   - Generated By, Position, Branch (left side)
   - Generated On, Time (right side)
   - Font size: 9pt
   - Border top

## Styling Specifications

### Colors
- **Header Background**: #E3F2FD (Light Blue)
- **Filter Background**: #F5F5F5 (Light Gray)
- **Stats Background**: #FFF9C4 (Light Yellow)
- **Table Header Background**: #1E3A8A (Dark Blue)
- **Table Header Text**: #FFFFFF (White)
- **Alternating Row 1**: #FFFFFF (White)
- **Alternating Row 2**: #F9FAFB (Light Gray)
- **Grand Total Background**: #E0E0E0 (Gray)
- **Border Color**: #333333 (Dark Gray)

### Fonts
- **Header Title**: Calibri, 20pt, Bold
- **Report Title**: Calibri, 16pt, Bold
- **Filters**: Calibri, 10pt, Bold
- **Stats Labels**: Calibri, 9pt, Bold
- **Stats Values**: Calibri, 18pt, Bold
- **Table Headers**: Calibri, 10pt, Bold
- **Table Data**: Calibri, 9pt
- **Grand Total**: Calibri, 9pt, Bold
- **Footer**: Calibri, 8pt

### Column Widths (Standard)
- **# Column**: 5 characters
- **ID Columns**: 15 characters
- **Name Columns**: 30 characters
- **Date Columns**: 15 characters
- **Amount Columns**: 15 characters
- **Status Columns**: 12 characters
- **Description Columns**: 40 characters

### Number Formats
- **Currency**: `₱#,##0.00`
- **Quantity**: `#,##0`
- **Percentage**: `0.0%`
- **Date**: `MMM DD, YYYY`

### Borders
- **All cells**: Thin border (#333333)
- **Header section**: All borders
- **Grand total top**: Medium border (2px)

### Alignment
- **# Column**: Center
- **Text Columns**: Left
- **Number Columns**: Right
- **Date Columns**: Left
- **Status Columns**: Center
