## Utility Functions Used

All reports use the following utility functions from `src/utils/excelExport.js`:

1. `createStyledWorkbook()` - Creates new workbook with metadata
2. `addReportHeader()` - Adds "DAVID'S SALON" and report title
3. `addFiltersSection()` - Adds filters applied section
4. `addSummaryStats()` - Adds summary statistics boxes
5. `addDataTable()` - Adds table headers and data rows with styling
6. `addGrandTotal()` - Adds grand total row (where applicable)
7. `addFooter()` - Adds footer with user info and timestamp
8. `setColumnWidths()` - Sets appropriate column widths
9. `saveWorkbook()` - Generates and downloads Excel file
