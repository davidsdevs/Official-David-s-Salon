# David's Salon Management System - User Manual Index

## Welcome to DSMS

The David's Salon Management System (DSMS) is a comprehensive cloud-based platform designed to streamline all aspects of salon operations, from appointment management to inventory control, billing, and reporting.

This user manual is organized by user role. Select your role below to access the relevant documentation.

---

## User Roles & Documentation

### 👥 **Client**
*Clients booking services and managing their salon experience*

- [Client User Manual](USER_MANUAL_CLIENT.md)
- **Key Features:** Browse services, book appointments, view promotions, manage rewards, track transactions
- **Access Level:** Public-facing portal with limited backend access

---

### 💇 **Stylist**
*Service providers managing their schedules and client interactions*

- [Stylist User Manual](USER_MANUAL_STYLIST.md)
- **Key Features:** View appointments, manage schedules, track commissions, build client portfolios, check-ins
- **Access Level:** Dashboard with stylist-specific views

---

### 📞 **Receptionist**

## Quick Reference

| Role | Access Level | Primary Tasks |
|------|-------------|----------------|
| Client | Public | Book appointments, view services, earn rewards |
| Stylist | Personal | Manage schedule, track commissions, portfolio |
| Receptionist | Branch | Handle appointments, billing, client check-ins |
| Branch Manager | Branch | Staff & operations management, reporting |
| Operational Manager | Multi-Branch | Performance monitoring, approvals, analytics |
| Inventory Controller | Branch | Stock management, purchase orders |
| Overall Inventory Controller | Organization | Global inventory oversight |
| System Admin | Full | Configuration, user management, system settings |

## Getting Started

1. **Log in** with your credentials
2. **Select your role** if you have multiple roles
3. **Navigate** to your role-specific manual above
4. **Explore features** relevant to your job function

## Common Features (All Roles)

Regardless of your role, you'll find these common features:

- **Dashboard** - Home page with role-specific summaries and quick stats
- **Profile** - View and manage your personal information
- **Notifications** - Stay updated with system notifications and alerts
- **Activity Logs** - View audit trails and system activities (admin roles)
- **Password Management** - Secure password updates

## System Overview

### Core Modules

- **Appointments** - Schedule and manage client appointments
- **Billing & POS** - Process payments and generate invoices
- **Inventory** - Track products and supplies
- **Reports & Analytics** - Generate insights and business reports
- **Staff Management** - Manage team members and schedules
- **Client Management** - Build and maintain client relationships
- **Promotions** - Create and manage promotional campaigns
- **Leave Management** - Handle staff leave requests
- **Deposits** - Track and reconcile bank deposits
- **Content Management** - Manage website and marketing content
