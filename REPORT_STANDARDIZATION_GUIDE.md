
# Report Standardization Guide
## Overview
All printable reports in the system should follow a consistent format with:
1. **"David Salon"** company name at the top
2. **Report title** centered below company name
3. **Active filters displayed in the center** (below title)
4. **Generated by [name]** at the bottom left
5. **Page numbers** in the center bottom (starting at Page 1)
6. **Generated on [date/time]** at the bottom right
7. **Poppins font** throughout the report

## Implementation

### 1. Import the Report Helpers

```javascript
import { 
  generatePrintableReport,
```

### 2. Get Current User

```javascript
const { currentUser } = useAuth();
```

### 3. Build Active Filters Array

Before generating the report, collect all active filters:

```javascript
const getActiveFilters = () => {
  const filters = [];
  
  if (dateFilter === 'custom' && startDate && endDate) {
    filters.push(`Date Range: ${formatDate(startDate)} - ${formatDate(endDate)}`);
  } else if (dateFilter !== 'all') {
    filters.push(`Date Filter: ${dateFilter}`);
  }
  
  if (branchFilter && branchFilter !== 'all') {
    filters.push(`Branch: ${branchName}`);
  }
  
  if (statusFilter && statusFilter !== 'all') {
    filters.push(`Status: ${statusFilter}`);
  }
  
  if (searchTerm) {
    filters.push(`Search: "${searchTerm}"`);
  }
  
  return filters;
};
```

### 4. Generate Report Content

Build your table/content HTML:

```javascript
const content = `
  <table>
    <thead>
      <tr>
        <th>Column 1</th>
        <th>Column 2</th>
        <th class="text-right">Amount</th>
      </tr>
    </thead>
    <tbody>
      ${data.map(item => `
        <tr>
          <td>${item.field1}</td>
          <td>${item.field2}</td>
          <td class="text-right">${formatCurrency(item.amount)}</td>
        </tr>
      `).join('')}
    </tbody>
  </table>
  
  <div class="summary-section">
    <div class="summary-row">
      <span>Subtotal:</span>
      <span>${formatCurrency(subtotal)}</span>
    </div>
    <div class="summary-row total">
      <span>Total:</span>
      <span>${formatCurrency(total)}</span>
    </div>
  </div>
`;
```

### 5. Generate and Print

```javascript
const handlePrint = () => {
  const filters = getActiveFilters();
  
  const reportHTML = generatePrintableReport({
    title: 'Sales Report',
    filters: filters,
    content: content,
    currentUser: currentUser
  });
  
  const printWindow = window.open('', '_blank');
  printWindow.document.write(reportHTML);
  printWindow.document.close();
  setTimeout(() => {
    printWindow.print();
  }, 250);
};
```

## Key Features

### 1. Consistent Header
- "David Salon" company name at top (14pt, semi-bold)
- Report title centered and bold (18pt)
- Active filters displayed as badges below title
- Professional appearance

### 2. Page Numbers
- Automatically generated using CSS counters
- Format: "Page X" (starts at Page 1)
- Centered in footer

### 3. Footer Information
- Left: "Generated by: [User Name]"
- Center: Page number
- Right: "Generated on: [Date Time]"

### 4. Print Optimization
- Letter size (8.5" x 11")
- Proper margins (0.4in sides/top, 0.75in bottom)
- Poppins font family throughout
- Ink-saving (no background fills)
- Page breaks handled properly
- Headers repeat on each page
